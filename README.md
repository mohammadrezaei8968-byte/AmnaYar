# AmnaYar | امنا یار

**AmnaYar (امنا یار)** is an online platform for practical validation services, official Iranian service links, and free everyday tools.

🌐 **Website:** https://amnayar.ir/  
🇬🇧 **English:** https://amnayar.ir/en.html  
📣 **Advertising:** https://amnayar.ir/advertising.html

## What AmnaYar offers

- National ID, bank card and IBAN validation
- Links to official Iranian services
- Free PDF, invoice, date, calculator, text and image tools
- Mobile-friendly web experience
- English introduction page for international discovery

## For brands

Brands and businesses can request direct advertising placements on AmnaYar. Campaigns can be configured with scheduled placement and performance tracking for impressions and clicks.

## Important

AmnaYar does not claim that validation tools replace official government services. Where an official service is required, the site directs users toward the relevant official channel.

If you want to collaborate or advertise, use the advertising request page above.
