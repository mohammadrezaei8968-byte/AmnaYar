قوانین استفاده از امنا یار

ماهیت خدمات

نتیجه صحت‌سنجی الگوریتمی به‌تنهایی اثبات مالکیت حساب یا هویت صاحب حساب نیست. استعلام رسمی تنها با سرویس مجاز مربوطه معتبر است.

اعتبار

هر عملیات سرویس می‌تواند طبق تعرفه جاری یک یا چند اعتبار مصرف کند. بسته‌ها و قیمت‌ها ممکن است از پنل مدیریت تغییر کنند.

استفاده مجاز

استفاده از سامانه برای فعالیت قانونی مجاز است و تلاش برای دور زدن محدودیت‌ها، سوءاستفاده از API یا ایجاد بار غیرعادی ممنوع است.

پرداخت و بازگشت

پرداخت مستقیم پس از تکمیل تنظیمات پذیرنده فعال می‌شود. شرایط بازگشت وجه و بررسی تراکنش باید در سیاست تجاری نهایی سامانه درج شود.
